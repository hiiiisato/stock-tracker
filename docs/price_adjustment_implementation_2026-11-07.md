# 価格調整の実装・移行記録（2026-11-07）

採用方針は無料ソース＋J-Quants Freeで取得可能になった日付の公式照合。追加の有料契約は使用しない。

## 原因と変更

キオクシアの取得が分割日をまたいで遅延し、新しく取得した分割後基準の価格を、古い未調整の履歴へ連結していた。旧方式の権利落ち日前後の段差検証は、この取得境界を見抜けなかった。さらに各画面に別の補正式があり、チャート一覧には生OHLC参照が残っていた。

取得原本（圧縮・ハッシュ付き）、公式の権利台帳と改訂履歴、当時値と調整済みOHLCV、銘柄別の公開状態を分離した。同じ日の公式当時値で取得基準を確認し、価格と出来高を独立に判定する。分割・併合・訂正・取消で台帳版が変われば、旧データへ追加の係数を掛けず原本から再生成する。

公開は銘柄別のトランザクション。更新中の台帳変更・古い取得結果による巻き戻しを拒否する。未確定・矛盾・取得不能な銘柄は通常表示から保留し、ほかの銘柄は進める。個別保留はpartialとして記録し、保留銘柄を正常価格として使わない。ウォッチリスト対象の保留、公式情報全体の取得停止、価格カバレッジ不足は日次の確定処理を止める。未対応の非監視銘柄だけで、無関係な銘柄の更新やレポートまで停止させない。

- 分析・チャートは `price_history`、当時の価格が必要な約定再現は `raw_price_history` を参照。
- 指標は元の価格版を保持し、`price_stats_current` が一致する版だけを返す。週次指標は `price_stats_history_current` が再生成時の系列版と一致する結果だけを返す。日々の追記では系列版を維持し、過去再生成時には全週を再計算する。完了記録は全週保存後に付け、途中停止から再開できる。
- キャッシュの共有世代を公開トランザクションで増加させ、複数ワーカーも5秒以内に失効する。画面復帰時も再取得する。
- 価格通知も公式台帳を使う。模擬運用の株数・取得単価・未約定注文は公式イベントで冪等に調整し、約定原本と現金は変えない。

## 無料データの扱い

JPXの予定表で権利落ち日を取得し、月報・会社の公式開示本文で比率を確定する。TDnetの短期URLが失効している場合は、同じ開示番号のJPX公開PDFへ切り替える。予定表の掲載期間を過ぎた候補は、保存済みの公式開示にある基準日と、欠落のない公式取引カレンダーから権利落ち日を検証する。株式無償割当ては追加割当率を総株数へ変換する（1:0.1 → 1:1.1）。予定表と比率台帳の取得失敗はバッチ失敗として扱う。

J-Quantsの照合対象は12週＋安全余裕1日を過ぎた日付。日付指定の全銘柄取得・全ページ処理を行い、日次処理と夜間処理に共通するDBのレート制限を使う。呼出間隔は16秒、429は65秒以上の共通待機期限を設定し、銘柄マスタAPIも同じ制御へ参加する。照合済み日、不一致、再試行日時を保持し、取得失敗や照合0件を成功扱いにしない。古い照合日も30日経過後に再検証する。終値だけでなく、当時値と調整済み値のOHLCVすべてを独立に比較する。

無料枠より古い分割などで取得基準を確認できない場合、取得可能な公式当時値の期間と、確認できた直近価格から再構築する。確認できない古い区間は原本・旧行に残し、通常のチャートに混ぜない。提供元の不正なOHLC、無約定日の幽霊行、実際の値動きを区別し、値幅だけを理由に価格を書き換えない。

## 実行と再開

```
python price_pipeline.py --migrate
python price_pipeline.py --sync-actions --history
python price_pipeline.py --repair
python price_pipeline.py --audit --check
```

対象限定は `--repair --codes 285A 5803 9984 1306 9282`。派生指標だけの再計算は `--refresh`。再生成後はテクニカル・財務比率・理論株価・ランキング・テーマ・直近週次指標を更新する。全銘柄の価格読取は100銘柄ずつに分割し、無料TiDBで数百万行を一括ソートしない。全期間の週次再計算は `python compute_stats_history.py --backfill`。

夜間00:30 JSTの既存サーバージョブ `.github/workflows/misc_batch.yml` へ台帳同期・遅延照合・保留銘柄の再生成を追加。1便の再生成は40銘柄まで、未試行・古い失敗から順番に処理する。価格品質の失敗がほかの巡回処理を止めないよう継続し、最後にジョブ全体へ失敗を反映する。Macの稼働には依存しない。
